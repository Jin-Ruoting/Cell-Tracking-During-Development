# 并行候选实验：E033 / E034 / E035

目标是在 E031 等待公榜评分期间，独立验证两个具有真实图像观测的补点机制，
以及后续登记的轨迹速度 EMA 对照。
每天最多五次正式提交；该额度用于通过验证的独立候选，不据此重复提交相同文件。
配置在新实验结果产生之前固定。

## 共用检测缓存

- 基础方法固定为 E029，沿用其两个已校验权重、D4 检测增强、`0.8` 次模型融合、
  `0.90` 候选保留保护和原始时间窗。主检测阈值仍为 `0.965`。
- 只在第一次处理某帧时，同时抽取概率大于 `0.3` 的真实局部峰，保存全分辨率
  `T/Z/Y/X` 坐标和概率；缓存阶段不读取标注、不评价或选择参数。
- 缓存捕获从固定版本的 E029 运行脚本派生，只跳过关联循环。原始推理产物保持
  不变，每部影片都必须与 E029 的 ILP 前检测坐标 SHA256 完全一致。
- 两部固定影片先验证运行与坐标尺度，再将固定 64 部影片按排序奇偶分给两张 GPU。
  不完整、重复、越界、非有限缓存或缺失影片均拒绝进入后处理。

## 两个独立候选

| 实验 | 固定变化 | 保持不变 |
|---|---|---|
| E033 | 回收距断轨起点/终点 `4 um` 内、概率至少 `0.965` 的自由检测峰，重算一次运动连接 | 原 E029 运动关联；不加入新的弱峰补轨 |
| E034 | 原补轨后，用真实峰桥接缺失 `1–3` 帧；峰概率至少 `0.5`，离线性路径最多 `3.5 um`，步长门限 `5 um`，保留方向检查，预算 `3%` | 原 E029 运动关联；不启用检测点回收 |

两项只提取 [x138](https://www.kaggle.com/code/anvithpothula/biohub-x138) 对应函数，
不执行其私有坐标头或标注驱动的搜索。自由峰统一排除距离已有节点不超过 `2 um`
的点。回收点函数本身没有 `3%` 上限，须单独报告实际加入与保留数量。

E034 禁止无观测的合成点。E033 不能通过将 `GAPFILL_MAX_GAP` 设为零关闭补轨，
因为参考实现的缓存加载也依赖该设置；两个插入点分别控制。所有缓存读取与回收
异常均应使实验失败，不能沿用参考中的静默回退。

## 判定与资源

- 固定对照为 E029 的完整 64 影片导出，后处理重放必须字节一致。
- 两部检查影片重新执行原始后处理；完整实验复用 E031 阶段已生成的 E029
  完整重放文件，并重新核对其全部字节与 E029 一致，不重复计算相同的对照。
- 两个候选使用同一缓存和同一官方评分器，分别输出结果；禁止在两部检查影片上
  选参数，禁止看到结果后组合两个组件。
- 沿用已固定的推进条件：总分至少增加 `0.001`，调整后边分数不降；两类胚胎、
  两半影片均改善；逐影片胜多于负，中位增益为正；图拓扑和完整覆盖均通过。
- 记录节点数、官方各分量、分裂 TP/FP/FN、补点分支调用次数、实际加入/保留节点
  和真实峰覆盖。重复使用的开发集不称为独立验证集。
- 完整缓存完成后可在两张 GPU 同时进行 E033/E034 后处理。正式候选仍需完成
  Kaggle 全流程运行、输出检查和提交记录核对；公榜分数以 API 结果为准。
- 另行准备 HOCT 共识删边对照，但它的依赖与输入审查未完成时不占用正式提交。

以上为结果产生前固定的实验设计；完成情况另列于文末，保留原推进门槛。

## E035：独立的轨迹速度 EMA 对照

后续检索发现 [JunhaoLiXD 的实验记录](https://github.com/JunhaoLiXD/Biohub_Cell_Tracking/blob/main/docs/experiments.md)
在较早的公开基线上测试了运动 EMA。本项目只借鉴这一算法方向并独立实现，
不将其作者报告的分数当成本项目证据，也不声称复现了其完整配置。

E035 固定 `alpha=0.4`，对已接受连接的物理位移按轨迹递推平均；首次连接的
速度由该位移初始化。在下一帧分配时，用平滑速度替代上一个单帧位移。
保持 E029 的速度权重 `0.25`、两轮分配门限、检测、分裂与所有补轨设置不变；
不加入 E031 邻域流或 E033/E034 补点。没有额外学习参数或外部权重。

同样先做固定两影片运行检查，再评分完整 64 影片；控制字节、官方评分和推进
门槛与上文相同。EMA 历史只能来自已经接受的前向连接，不能读取未来 GT。
两项语义检查分别验证定位抖动时的分配变化、匀速/新轨迹的原行为保留。
