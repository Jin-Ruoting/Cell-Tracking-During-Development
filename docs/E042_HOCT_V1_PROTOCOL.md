本方案在 v1 首次真实图像推理及质量评分前固定。v1 的完整官方资产已在
Kaggle 和服务器通过校验与 CPU 加载；这仅证明可用性。可证伪假设是：
在相同固定节点、图像特征、上游尺度修复与删边策略下，v1 的连边判断比
v0 更可靠，并能在 E029 上产生可推广的开发增益。

## 预定判定

完整 64 部需同时满足：相对原 E029 官方总分至少增加 `0.001`，调整后边
分数不降，两胚胎及交替两半均为正，受影响影片胜多于负且中位增益为正。
此外 v1 完整官方总分必须高于相同尺度的 v0，才支持本次权重升级假设。
报告逐片变化、配对胜/负/平及中位数，区分汇总增益与影片间稳定性。

沿用 E029 可见作者选片五部的排除审查：去掉 `44b6_12dfb391`、
`44b6_267148e4`、`44b6_2a2eff9f`、`44b6_341df25f`、`6bba_09961292`
后，剩余 59 部全体及两胚胎相对 E029 的总分增益均须为正。HOCT 权重的
完整训练影片清单和参考作者的 20 部选片尚不明，不能声称训练独立留出。

任一质量门槛失败则拒绝推进，不在这些结果上改半径、尺度、邻居数、阈值、
求解参数或分裂处理后重选。完整开发通过也不等于公榜成功；须另做正式
输出审查与 Kaggle 提交，最终以公榜超过 E029 的 0.947 并进入前 10% 为准。
本运行器只生成开发比较，不提交比赛。
