# V12 真实帧接口检查

本检查回答一个技术问题：已通过严格权重加载的 v12，按作者公开图像约定，
能否在真实帧上返回有限的检测坐标和可解释的相邻帧连接。它不检验追踪优劣，
不训练、不调参、不计算官方分数，也不形成比赛提交。

## 固定输入与实现

- 固定影片 `44b6_eb2880fc`、`6bba_969618f6`，每部只读第 0、1 帧。
  这延续既有技术检查影片，不根据 v12 的表现选片。
- 只打开训练图像 Zarr 及其图像属性；不打开 GEFF、测试图像或标签。
  直接读取 `image_statistics.quantiles` 与空间尺度，该字段路径已对照公开
  支持包 `biohub_tracking/io.py`；空间尺度缺失时沿用该加载器的明确默认值，
  并单独记录来源。不使用需要轨迹的作者演示加载调用。
- 固定权重 SHA256
  `ecd8869de9cf405c1a93a563b4810faad5fd2378f57341e18c4e6b5a87201552`；
  保留完整大小、ZIP CRC、源码校验及 `weights_only=True` 受限加载。
  仅把已经审查的 `DotDict` 名称映射到内置字典。严格加载全部模型参数。
- 使用检查点的 `unet_cfg` 与 `tx_cfg`：节点上限 1024、峰阈值 0.2、核 3，
  记录轮次 8。采样、归一化与半径 3 网格体素聚类取自
  [作者演示](https://www.kaggle.com/code/hengck23/end2end-cell-linker-raw-edge-ja-0-9-no-ilp)。
  对完整 Notebook 固定 SHA，再私有打包三个已审查的后处理函数；不执行其
  原始数据加载、标签评价或训练代码，不将第三方源码加入公开 Git。
- 连边保留作者的双向分数、空连接 logit 0、累计概率 0.99 与 top-1 终点
  冲突处理。只输出计数和审查回执，不导出候选提交。

## 计算与结果边界

使用私有、离线 Kaggle CPU，FP32，两帧为一批，4 个计算线程；Notebook
硬上限 25 分钟，运行子进程上限 20 分钟。这是资源上限，不是耗时预测。
作者演示使用 GPU FP16 和最多 21 帧一批；本检查不主张与其逐位一致，
CPU 耗时也不能直接充当 GPU 全量预测预算。

通过条件为输入尺度/类型正确、受限严格加载成功、全部指定帧完成、坐标与
连接 logits 有限且在 CPU、选边端点存在且无入出度冲突。独立记录越界细化
坐标数量；不静默裁剪或删除。接口完成与图坐标有效性分别报告，越界未处理
时不能进入完整图输出。记录归一化范围、聚类前后节点数、空连接数、耗时
和进程峰值内存。失败保留原回执，不据此搜索阈值。

无论技术结果如何，都不构成模型改进或正式提交资格。后续若研究 v12 关联，
必须先固定与 E029 的接合方式、分裂/边界规则、完整开发集合和官方评分门槛。
训练影片排除未知，所有质量比较仍只能称开发证据。

## 运行入口

本地只进行已提交且推送后的代码打包：

```sh
python3 kaggle/check_v12_real_frames.py package \
  --owner KAGGLE_OWNER \
  --reference-notebook /outside-repository/author-demo.ipynb \
  --output-dir /outside-repository/private-v12-package
```

Kaggle CLI 使用 CPU Notebook、1500 秒上限。运行入口拒绝在本地执行模型。
云端回执写到 `/kaggle/working/logs/v12-real-frames`；下载后进入本地被忽略的
`logs` 目录。源码变化与实际结果分别记录到项目 Markdown。
